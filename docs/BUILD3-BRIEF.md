## Deliverables

1. **Fact Graph flagship demo (synthetic).** A scripted agent session inside the Firecracker guest works a synthetic individual return end to end: intake values land in a workspace, a pipeline computes the return, and the IRS Fact Graph (CC0) dependency graph is the pipeline's layer-3 graph. The exported viewer shows the full stack on one timeline: scrub the terminal, click a computed figure on the return, and walk its provenance down through the Fact Graph path to the exact intake bytes that produced it (rung-4 lazy taint + rung-2 graph), then fork at a checkpoint, clamp one intake value (Jeff's edit doctrine: clamp = do-operator), and watch dependents-only recompute produce the amended figure on the new branch while the parent branch stays byte-identical.
2. **GUI surface, viewer-first.** A second surface beside the terminal: capture a scripted GUI session inside the guest (framebuffer grabs at input-event boundaries, keyframes + delta log on the same hash-chained timeline), replay/scrub it in the exported viewer next to the terminal surface, with per-region provenance where the surface can honestly supply it (window/element identity when the guest toolkit exposes it; pixel-region -> input-event otherwise, labelled as such). No AT-SPI claims beyond what is measured; Electron/renderer accessibility is out of scope for this build.
3. **At-rest encryption.** Timeline store and content-addressed payloads encrypted at rest (per-timeline key, standard AEAD construction, key supplied out-of-band and never written to the timeline directory). Redaction-at-capture (Build 1 G4) stays the first line; encryption is the second. Fork, replay, viewer export (with an explicit decrypt-for-export step Jeff controls) and the gate corpus all work against encrypted stores.
4. **Solver rung 4 for opaque binaries (PANDA spike, time-boxed).** Inside the guest only: record one scripted session where a compiled helper binary (source known to the test, treated as opaque by the tooling) transforms an input file; on a provenance query for the output, PANDA-style whole-system byte taint over the recorded slice names the input byte ranges that flowed into the output. This is a spike with a measured result, not a promise: if taint cannot be made to produce exact ranges on the corpus binary, the deliverable is the failure report with the measured gap, and rung 4 stays scoped to declared pipeline steps.
5. **Alt-screen resolution.** Close Build 1's flagged non-claim one way or the other: either the grid model implements xterm buffer-restore semantics for the alternate screen and G1 is re-measured against a reference that exercises it, or the corpus proves the pyte no-op semantics match the workloads the product actually records, and the non-claim is rewritten as a scoped claim with that evidence.
