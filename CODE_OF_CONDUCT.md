# Code of Conduct

Melange is a small project with a simple standard: we argue with the
work, and we respect the people.

## Expected behavior

- Critique ideas, code, and measurements. Bring evidence, and expect
  to be asked for it.
- Disagree plainly and move on once a decision lands.
- Help newcomers orient. Everyone here started by reading the same
  docs.
- Credit other people's work where it shaped yours. The README does
  this and contributions should too.

## Not acceptable

- Harassment, threats, or personal attacks, in any project space.
- Publishing someone else's private information.
- Sexualized or inflammatory content in issues, pull requests, or
  discussions.
- Sustained disruption after a maintainer has asked for it to stop.

## Enforcement

The maintainer reviews reports and decides the response, from a
private note to removal from the project spaces. To report a problem,
message the maintainer through GitHub. Reports stay confidential.

This project values directness. A sharp technical disagreement is
welcome here; it stays about the work, and it ends when the evidence
is in.
